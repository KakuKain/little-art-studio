# 小小畫室
給幼兒使用的手機畫畫工具。無登入、廣告、付費牆或外部服務。

功能：貓咪／公主 SVG 塗色、自由畫板、一般筆和彩虹筆、橡皮擦、20 步復原／重做、全部顏色、自訂色、IndexedDB 自動保存與最近 20 張作品、PNG 匯出、PWA 離線快取。

首次連網載入後可離線使用。作品僅存在目前瀏覽器；清除網站資料會移除作品，重要作品請下載。復原紀錄只在本次開啟期間保留。

本機：`python3 -m http.server 8080`。部署：GitHub Pages 從 main 分支根目錄發布。

更新：畫筆／彩虹筆／橡皮擦會鎖定下筆所在的可見區域，保留線框和重疊區域。主畫面無文字說明，使用縮圖選圖、圖示工具列與選色視窗；提供固定色盤和色相／濃淡／明亮滑桿。

首頁以縮圖選擇公主、貓咪或空白畫布；進入後是全寬全高畫布與底部工具列。空白畫布可以畫到四邊，回首頁保留目前作品。

著色紙含貓咪、公主、兔子、冰淇淋和城堡原創 SVG 線稿。背景填色覆蓋全畫布，資源版本和網路優先快取避免載入舊版固定範圍。

分類著色庫：15 位公主（含艾莎、安娜）、夜煞與光煞、三隻小龍及全家組圖、救援騎士、佩佩豬、6 種海洋生物與 6 種陸地動物。線稿由圖片自動描成 SVG，保留可填色區域和輪廓。點畫筆可選四種粗細。來源與使用條件記錄於 assets/coloring/SOURCES.md 和 catalog.json。角色生成稿可能與原作有所差異。

描圖：安裝 Pillow、numpy、opencv-python-headless 後執行 `python scripts/trace-coloring.py input.png output.svg`。原始 PNG/WebP 留在本機同一資料夾，不加入發布檔案；網站及离線快取使用 SVG。
