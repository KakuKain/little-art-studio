# 小小遊樂園 UI 規格書

版本：1.0.0-beta.10 · 2026-10-30。原名「小小畫家」。設計方向：樣板 2「簡約童趣風」。適用現行 GitHub Pages 網站。

## 使用對象與流程

主要使用者為約 3–6 歲兒童，以手機手指操作為主。首頁是遊戲選單（著色畫畫、方塊出門、動物餐廳）。著色畫畫 → 分類 → 圖片 → 畫布，分類頁另有空白畫布；方塊出門與動物餐廳從首頁直接進入。每次進入網站（重新整理、重新開啟、從瀏覽紀錄返回）都從首頁開始，不直接跳到畫布；作品仍保存，選同一張圖即可接續。家長可在資訊頁安裝 App、下載離線分類，在相簿重新編輯或下載作品。主要裝置為 Android 手機與平板。

## App 化（Android）

- 版本：「關於遊樂園」顯示目前版本（例如 v1.0.0-beta.1），方便家長回報問題。
- 家長鎖：首頁齒輪與畫布「更多」裡的「關於遊樂園」要按住 2 秒才打開（按住時齒輪外圈逐漸填滿），輕點只提示「請家長按住 2 秒」；鍵盤按 Enter 直接打開。裡面的圖片來源連結收在「圖片來源」裡，預設摺起來。
- 聲音：遊戲有程式產生的音效（不下載音檔）：送對食物「啵」、點了沒點的食物低低的「咚」（不是錯誤聲）、貓咪被擋住時同樣的「咚」、貓咪回家「喵」、過關四個上升的音；著色畫畫填色「啵」、清除「咻」，「完成」時同樣有上升的音。首頁點遊戲卡片會唸出名稱；著色畫畫不說話。動物餐廳的客人用裝置的中文語音（優先 zh-TW）說出想吃什麼，例如「小貓想吃一條魚」，數量用國字、二說成「兩」；每送一份就數出來（一、兩、三…）；點客人再說一次，送齊說「謝謝！」。裝置沒有中文語音時不說話，不用其他語言的聲音硬讀。遊戲畫面隱藏時不出聲，離開遊戲會停止說話。「關於遊樂園 → 聲音」可關掉全部聲音，選擇存在這台裝置，預設開啟。
- 安裝：「關於遊樂園 → 安裝到主畫面」。Chrome 提供安裝時顯示「安裝小小遊樂園」按鈕，否則說明從 Chrome 選單（⋮）選「安裝應用程式」；已安裝並從主畫面開啟時不顯示此區塊。Chrome 自動跳出的安裝橫幅被停用，避免兒童誤觸。
- 圖示與開啟畫面：192／512 PNG 圖示及可裁切為任意形狀的 maskable 圖示；Android 以圖示與背景色 #F7FAFC 自動產生開啟畫面。從主畫面開啟為 standalone，不顯示網址列。
- 返回鍵：每個畫面是一筆瀏覽紀錄。Android 返回依序為畫布 → 分類 → 著色畫畫 → 首頁 → 離開 App，遊戲畫面返回首頁；分類頁的捲動位置保留。畫面上的回選圖、回分類箭頭與返回鍵相同；回首頁按鈕直接回到第一層。圖片載入中按返回則不再進入畫布。
- 手感：不能兩指縮放或雙擊放大；頁面不彈跳、不會下拉重新整理；長按圖片或按鈕不出現選單、不選取文字；點擊無藍色閃光；按鈕按下縮小。首頁與分類以 200ms 淡入上移出現，畫布只淡入不位移；系統設定減少動態效果時不播放。

## 首頁（遊戲選單）

標題「小小遊樂園」與副標「畫畫、動動腦，一起來玩吧！」，下方每個遊戲一張大卡片：手機一欄寬卡片，圖在左、右邊是遊戲名稱和一句說明（選一張圖塗上顏色／幫貓咪走到同顏色的門／端出客人想吃的食物），三張剛好排滿畫面；寬 ≥600px 三欄直式卡片；手機橫拿時不顯示說明。卡片圖：著色畫畫（塗了一半的花朵著色紙與兩支蠟筆）、方塊出門（三隻疊羅漢的貓咪：粉紅愛心眼、藍、黃）、動物餐廳（小熊與一盤蘋果、甜甜圈）。卡片上不顯示關卡或張數，首頁只是選遊戲的地方，不比進度。點卡片會唸出遊戲名稱。右上為作品相簿與設定。之後新增的遊戲以同樣卡片加入。

## 方塊出門

- 規則：方格盤面上有彩色方塊，邊緣有彩色的門。用手指拖方塊，方塊一格一格跟著手指走，碰到其他方塊或牆就停。手指按在方塊之間的縫隙或圓角上也算拿起該方塊；直直拖的時候手指往旁邊偏不到 3/4 格，方塊不會換行或換列；在門旁邊往外推也不會滑進門裡出去，要真的對準門才會出門。貼著牆沿邊滑到門口時，貓咪會先到門口那一格，再從門出去，不會看起來從門旁邊穿牆。拖到與自己同色、且寬度容得下的門前放手就會出門（直接推出門也可以）。全部方塊離開即過關。沒有計時、生命值、廣告或付費道具。
- 場景：暖色調的兒童房（書架、盆栽、玩具、地毯，直拿和橫拿各一張圖），中間一塊米色格子遊戲墊圍著木頭外框。外框是一整張圖跟著盤面縮放，木頭寬度約是盤面的 6%，不管幾格都一樣粗。門是躺在外框上的彩色圓角條，長度是門的寬度減去 0.2 格，置中在門的範圍。方塊是生成的粉彩貓咪圖：1×1 是圓圓的貓頭，橫的兩格是趴著的貓（尾巴捲在後面，依編號朝左或朝右），直的兩格是坐著的貓（下方露出前腳和捲尾巴）。每隻貓都是圓的黑色豆豆眼、粉紅鼻子、ω 嘴、鬍鬚和腮紅，整隻貓畫在自己的格子裡。拿起時放大一點、有影子。前三關的提示是「把貓咪拖到同顏色的門」。拿起貓咪時，牠的門一大一小地跳動發光，其他門變淡。按鈕、關卡名稱和小貓頭列是米色圓角底，燈泡提示鈕是黃色的長圓鈕。
- 教學與提示：第 1、2 關會有一隻半透明的白色手，示範把下一隻能回家的貓咪拖出牠的門，一直重複，直到孩子碰盤面；一隻貓咪回家後再示範下一隻。盤面下方（手機橫拿時在右下角）有燈泡提示鈕：按下去，現在就能回家的一隻貓咪搖一搖，牠的門發光；如果盤面被推到沒有貓咪能直接回家，就改成讓「上一步」（或「重來」）搖一搖。系統設定減少動態效果時，手停在貓咪身上不動，貓咪和門也不晃動。
- 只靠顏色配對：貓咪和門不另外加形狀或圖案。
- 關卡（小朋友）：第 1 關 3×3 一個方塊，第 2 關示範「先讓路」，第 3–14 關 4×4、第 15–45 關 5×5、之後 6×6，方塊數與一開始被擋住的方塊數慢慢增加（第 70 關前最多 8 隻、被擋住的最多 2 隻），並出現兩格長的方塊。
- 大人版：另一套關卡，第 1–10 關 6×6、第 11–30 關 7×7、之後 8×8，8–16 隻貓、一開始 4–6 隻以上被擋住，要先想好順序。標題顯示「大人・第 N 關」，沒有提示文字與手指示範，進度和小朋友分開記。每一關固定（每台裝置相同），且經程式確認依序移出方塊即可解開，不會卡死。
- 介面：上排左邊返回，右邊上一步、重來、選關卡；「第 N 關」在按鈕列下面自己一行（手機橫拿時放在上排正中間，留高度給盤面），前三關在它下面顯示「把貓咪拖到同顏色的門」。下方一排白底小貓頭是這關的所有貓咪，還在盤面上的是灰色，回到家就變回原色並跳一下（上一步會變回灰色）；手機橫拿時不顯示，留給盤面。過關時遊戲畫面蒙上一層暖色漸層並模糊，中間彈出一張卡片（見下方「過關卡片」），卡片插圖是疊羅漢貓咪，好朋友列是這關回家的小貓頭，同時落下彩色紙花。選關卡上方有「小朋友／大人」切換，下面是「繼續第 N 關」大按鈕（就是目前關卡時不顯示）與關卡格；超過 20 關時一頁 20 關，用 ‹ › 翻頁，一開始停在目前關卡那頁；已過關的關卡淡綠底、右上有金色星星。貓咪被牆或其他貓擋住、手指拉超過約一格時，貓咪往那邊輕輕彈一下並「咚」一聲。進度（目前關卡、已解鎖關卡）存在這台裝置；離開遊戲再回來會停在同一盤面。

## 動物餐廳

- 規則：動物客人一位一位來，對話泡泡顯示想吃的食物，每種一列、要幾個就畫幾個。點下方食物櫃的食物，食物飛進泡泡，對應的格子由半透明虛線框變成全彩。點了沒點的食物或已經夠了，食物只輕輕搖一下，不扣分、不計錯。點齊後泡泡顯示「❤️ 謝謝！」，動物跳一下後離開，下一位進來。當天的客人都吃飽就過關。沒有計時、生命值、廣告或付費道具。
- 圖案：動物（正面頭像）與食物（每張一份）是同一風格的手繪感插圖：圓潤扁平、深咖啡色粗描邊、粉彩配色、透明背景，每台裝置看起來都一樣，不使用系統 Emoji。食物有中文名稱與量詞（兩根香蕉、一杯牛奶），提供給螢幕閱讀器。
- 關卡：第 1–2 關三位客人，各點自己最愛的一樣食物（兔子紅蘿蔔、猴子香蕉、老鼠起司、小熊蜂蜜、小貓魚、小雞玉米），食物櫃三格。之後食物櫃 4–8 格、每天 4–5 位客人，一次點的種類（1–3 種）與數量逐步增加，第 25 關起同一種最多 5 個，練習數到五。每一關固定（每台裝置相同）；同一隻動物不會連續出現。
- 教學：第 1、2 關每位客人來了約 1.2 秒後，一隻白色的手在食物櫃上點兩下客人要的食物，一直重複，孩子點食物櫃就消失；下一位客人來時再出現。系統設定減少動態效果時，手停在食物上不動。
- 場景：一間小餐廳，條紋壁紙、三角旗、窗戶與吊燈，下方是木頭櫃台。客人站在櫃台後面，下巴被櫃台邊緣擋住一點，跳起來時從櫃台後冒出；食物櫃放在櫃台上。牆面與櫃台依螢幕高度延伸，任何比例都不裁掉窗戶和裝飾；直向與橫向各用一張背景。
- 介面：上排左邊返回，右邊選關卡；「第 N 關」在按鈕列下面（手機橫拿時在上排正中間），前兩關在它下面顯示「點動物想吃的食物」。泡泡裡每一列食物右邊有粉紅圓圈數字，表示要幾個。標題下方白色膠囊裡的圓點表示今天的客人：已吃飽粉紅、目前黃色、還沒來淺棕，都有深色描邊，在條紋壁紙上也看得清楚。手機直向時客人在上、食物櫃在下，客人和泡泡隨螢幕高度放大（812px 高的手機約 150px 的動物、47px 的食物格，平板最大 200px／60px），360×640 的小手機也放得下三排的訂單；橫向（寬 ≥600px）客人在左、食物櫃在右。過關彈出同樣的過關卡片：插圖是小熊與餐盤，緞帶寫「客人都吃飽了！」，好朋友列是今天所有客人的頭像，同時落下彩色紙花；選關卡同樣以星星標出已過關的關卡。離開遊戲再回來會接續同一位客人。系統設定減少動態效果時，食物不飛行、客人不移動、不落紙花。

## 過關卡片（兩個遊戲共用）

- 遊戲畫面蒙上暖黃、粉紅到淡藍的放射漸層並稍微模糊；卡片從下方彈起放大出現。
- 卡片上方是遊戲插圖，一半伸出卡片外，背後是慢慢旋轉的黃色放射光芒；插圖從上方彈跳落下。
- 插圖下三顆金色星星依序轉著跳出（中間那顆較大較高）。只是慶祝，不評分，每次都是三顆。
- 粉紅色緞帶寫著「過關了！」或「客人都吃飽了！」，兩端的緞帶尾巴折在後面。
- 好朋友列：方塊出門是這關的小貓頭，動物餐廳是今天的客人，一隻隻跳出來。
- 黃色大按鈕「下一關 ›」（最寬 240px、高 64px），下面是白色的「↻ 再玩一次」。
- 手機橫拿時，插圖在左、星星到按鈕在右，整張卡片放得進 375px 高的畫面。系統設定減少動態效果時，卡片、光芒、插圖、星星與好朋友都不動。

## 著色畫畫：分類與選圖

七分類：公主、馴龍高手、救援騎士、佩佩豬、蓋比娃娃屋、海洋生物、陸地生物；加上自由畫畫（白紙上畫著太陽和彩虹、旁邊三支蠟筆的彩色插圖），共八張卡片。首頁只載入分類 PNG，不載入所有著色圖。分類頁使用 lazy 載入的 WebP 縮圖（360×440）。往下捲時返回與標題固定在上方。標題下方三顆大按鈕「簡單／全部／細節多」切換難度，預設簡單，每次進入分類都回到簡單。畫過的圖（有任何筆畫或填色）右上角有綠色勾勾，從畫布返回時更新。

白底、淡色卡片、藍色標題、角落裝飾只在遊戲選單首頁及桌機畫布周圍，分類頁與選圖頁不顯示。分類頁頂部背景透明，避免不同色塊形成突兀橫條。

## 畫布與操作

畫布使用所有可用區域；手機不加外框。主體完整等比例顯示，不裁掉頭、腳、翅膀或尾巴。導覽覆蓋畫布上方，主體保留 64px 上方與 24px 下方空間，左右至少 16px。

上方：左側回選圖，中間上一步／下一步／清除，右側黃色星星「完成」與回首頁；按「完成」會把作品（裁成相簿的畫框比例）放進木框，用遊戲的過關卡片展示：三顆星星、緞帶「畫好了！」、紙花，按鈕「再畫一張 ›」（回選圖頁）、「看相簿」與「繼續畫」，點卡片外面也會回到畫布。沒有語音。清除和回首頁分開，避免想回首頁時誤按清除。清除要按兩下：第一下按鈕變紅、搖一搖並提示「再按一次就會清除」，3 秒內再按一次才清除，否則恢復原狀。手機操作用圖示，不加功能說明文字，保留 aria-label。清除與繪圖工具分開放置；清除可復原。

繪圖工具：鉛筆、粗細、填色、橡皮擦、更多。粗細是三顆大小不同的圓點（細 6、中 12、粗 26 CSS px），每顆 36×48px，選中的有淡藍外框；桌機直向排列。線稿圖每次進入預設填色（點一下就塗滿一塊），自由畫畫預設鉛筆；粗細預設為中；鉛筆與橡皮擦各自記住本次開啟期間的粗細。填色時停用粗細。填色圖示是倒出顏料的油漆桶，桶口與顏料滴是目前選的顏色，和清除用的垃圾桶分得開。

顏色排：最左是調色盤圖示（右下角的小圓點是目前顏色），點開面板；中間粉紅、黃、綠、藍、紫、膚色、棕七色（膚色與棕色給臉和頭髮用）；最右彩虹筆。面板提供 18 個固定色（每排六色，含淺膚色、膚色、深膚色）與彩虹筆；色相／彩度／明度混色收在「調出自己的顏色」裡，預設摺起來，避免小小孩誤入。選固定或自訂色時退出彩虹模式。彩虹筆的顏色隨筆畫距離連續漸變（每 SVG 單位 2°），即使快速畫出、取樣點很少的長線，也以漸層連接，不會變成單色色塊。

筆畫鎖定首次落筆的區域。只有觸控、觸控筆與滑鼠左鍵會下筆；離開畫布（上一頁、返回手勢）時仍按著的筆畫會結束並保存，回到首頁後可正常操作。填色使用同一個語意區域，群組區域一起換色；相同顏色不增加復原步數。橡皮擦移除筆跡，顯示其下原有填色或白底，線稿保持完整。清除重設筆跡與填色。復原／還原每份作品各自保留最近 20 步，重新整理後仍可用；不切換到其他圖片。重畫期間連按復原／還原會合併成一次，不會漏按；重畫在畫面外完成後一次換上，不顯示畫到一半的畫面。

更多為靠近按鈕的 popover 選單，點外面或 Escape 收起，支援方向鍵。手機選單提供儲存、全螢幕、關於遊樂園；桌機另有可見的儲存與全螢幕按鈕。來源資訊只放在關於遊樂園。

## 相簿與離線

相簿只放有內容的作品：還有沒被復原的筆畫或彩色填色（最後一次清除之後），全部按上一步復原的作品不放進相簿，選圖頁也不打勾。家長按住作品 2 秒，作品漸漸變淡，接著出現紅色「刪除」與「留著」；刪除後作品從相簿與這台裝置移除。相簿中的新版縮圖是「繼續畫」按鈕，回到同一作品 ID；另存 PNG 使用畫布儲存功能。舊版相簿 PNG 保留下載入口。開相簿、切圖或重複儲存，更新同一份作品，不新增一張重複縮圖。相簿縮圖裁成 360:440，範圍是整張圖（或圖片的 bounds）往兩側或上下補足比例，不裁到圖；自由畫畫保持原比例。都放在 360:440 的白底框裡；框在圖片載入前就佔好位置，相簿不會跳動。還沒有作品時顯示「還沒有作品，去畫一張吧！」。

資訊頁的離線分類選單顯示已下載／總數。下載按鈕下載該分類所有難度，以兩個工作同時處理；完成後按鈕停用。失敗保留已完成的下載，可再試。介面與圖片各自快取，介面更新不清除已下載圖片。

## 視覺 token 與狀態

| Token | 值 |
|---|---|
| 背景／畫布 | #F7FAFC／#FFFFFF |
| 文字／次要文字 | #263238／#607D8B |
| 邊線／重點 | #E8EEF2／#087BAC |
| 選取工具底色／輪廓 | #FFF0BD／#E9BD44 |
| 分類卡 | 淡粉、淡黃、淡綠、淡紫、淡藍、淡橘、淡草綠 |
| 字體 | 系統繁中字體；不另載外部字體；全站文字 `text-wrap: pretty`，最後一行不只剩一個字；「關於遊樂園」另用 `word-break: keep-all`，中文只在空白與標點處換行 |
| 圓角 | 卡片與對話框 24px，工具 14–16px |

選取工具有底色與輪廓；色票選取有外圈；不可復原或還原時按鈕停用。非同步切圖／復原期間阻擋重入，成功或失敗後恢復操作。儲存與下載錯誤以短暫 status 提示呈現，平常畫布不顯示技術文字。

錯誤或儲存提示保留輔助科技 status；圖示有文字替代，鍵盤焦點有外框；尊重 reduced-motion。對話框可以點外面、關閉或 Escape 收起。舊分頁阻擋資料升級時，最長等待三秒後仍可操作，提示關閉其他遊樂園分頁並重新整理以恢復保存；不清除既有資料。另一個分頁升級資料時，本頁釋放連線並提示「遊樂園已在其他分頁更新，回到首頁會重新整理」，之後不再誤報儲存空間不足；回到首頁時自動重新整理。
