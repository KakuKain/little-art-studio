# 小小畫家 UI 規格書

版本：V49 · 2026-10-10。設計方向：樣板 2「簡約童趣風」。適用現行 GitHub Pages 網站。

## 使用對象與流程

主要使用者為約 3–6 歲兒童，以手機手指操作為主。首頁 → 分類 → 圖片 → 畫布；首頁另有空白畫布。每次進入網站（重新整理、重新開啟、從瀏覽紀錄返回）都從首頁開始，不直接跳到畫布；作品仍保存，選同一張圖即可接續。家長可在資訊頁安裝 App、下載離線分類，在相簿重新編輯或下載作品。主要裝置為 Android 手機與平板。

## App 化（Android）

- 安裝：「關於畫室 → 安裝到主畫面」。Chrome 提供安裝時顯示「安裝小小畫家」按鈕，否則說明從 Chrome 選單（⋮）選「安裝應用程式」；已安裝並從主畫面開啟時不顯示此區塊。Chrome 自動跳出的安裝橫幅被停用，避免兒童誤觸。
- 圖示與開啟畫面：192／512 PNG 圖示及可裁切為任意形狀的 maskable 圖示；Android 以圖示與背景色 #F7FAFC 自動產生開啟畫面。從主畫面開啟為 standalone，不顯示網址列。
- 返回鍵：每個畫面是一筆瀏覽紀錄。Android 返回依序為畫布 → 分類 → 首頁 → 離開 App；分類頁的捲動位置保留。畫面上的回選圖、回分類箭頭與返回鍵相同；回首頁按鈕直接回到第一層。圖片載入中按返回則不再進入畫布。
- 手感：不能兩指縮放或雙擊放大；頁面不彈跳、不會下拉重新整理；長按圖片或按鈕不出現選單、不選取文字；點擊無藍色閃光；按鈕按下縮小。首頁與分類以 200ms 淡入上移出現，畫布只淡入不位移；系統設定減少動態效果時不播放。

## 首頁與選圖

七分類：公主、馴龍高手、救援騎士、佩佩豬、蓋比娃娃屋、海洋生物、陸地生物；加上自由畫畫，共八張卡片。首頁只載入分類 PNG，不載入所有著色圖。分類頁使用 lazy 載入的 WebP 縮圖（360×440），預設簡單，可選全部或細節較多。

白底、淡色卡片、藍色標題、裝飾只在首頁及桌機畫布周圍。分類頁頂部背景透明，避免不同色塊形成突兀橫條。

## 畫布與操作

畫布使用所有可用區域；手機不加外框。主體完整等比例顯示，不裁掉頭、腳、翅膀或尾巴。導覽覆蓋畫布上方，主體保留 64px 上方與 24px 下方空間，左右至少 16px。

上方：左側回選圖，中間上一步／下一步，右側清除與回首頁。手機操作用圖示，不加功能說明文字，保留 aria-label。清除與繪圖工具分開放置；清除可復原。

繪圖工具：鉛筆、獨立粗細滑桿、填色、橡皮擦、更多。每次進入作品預設鉛筆；鉛筆與橡皮擦各自記住本次開啟期間的粗細。初始 12 CSS px，範圍 5–40 CSS px；滑桿不開啟 modal。填色時停用粗細。

顏色排：最左目前顏色，點開面板；中間粉紅、橘、黃、綠、藍、紫六色；最右彩虹筆。面板提供 15 個固定色、色相／彩度／明度混色及彩虹。選固定或自訂色時退出彩虹模式。彩虹筆的顏色隨筆畫距離連續漸變（每 SVG 單位 2°），即使快速畫出、取樣點很少的長線，也以漸層連接，不會變成單色色塊。

筆畫鎖定首次落筆的區域。只有觸控、觸控筆與滑鼠左鍵會下筆；離開畫布（上一頁、返回手勢）時仍按著的筆畫會結束並保存，回到首頁後可正常操作。填色使用同一個語意區域，群組區域一起換色；相同顏色不增加復原步數。橡皮擦移除筆跡，顯示其下原有填色或白底，線稿保持完整。清除重設筆跡與填色。復原／還原每份作品各自保留最近 20 步，重新整理後仍可用；不切換到其他圖片。重畫期間連按復原／還原會合併成一次，不會漏按；重畫在畫面外完成後一次換上，不顯示畫到一半的畫面。

更多為靠近按鈕的 popover 選單，點外面或 Escape 收起，支援方向鍵。手機選單提供儲存、全螢幕、關於畫室；桌機另有可見的儲存與全螢幕按鈕。來源資訊只放在關於畫室。

## 相簿與離線

相簿中的新版縮圖是「繼續畫」按鈕，回到同一作品 ID；另存 PNG 使用畫布儲存功能。舊版相簿 PNG 保留下載入口。開相簿、切圖或重複儲存，更新同一份作品，不新增一張重複縮圖。相簿縮圖保持原比例。

資訊頁的離線分類選單顯示已下載／總數。下載按鈕下載該分類所有難度，以兩個工作同時處理；完成後按鈕停用。失敗保留已完成的下載，可再試。介面與圖片各自快取，介面更新不清除已下載圖片。

## RWD

| 情境 | 首頁 | 選圖 | 畫布工具 |
|---|---|---|---|
| 手機 <768px | 2 欄 | 2 欄 | 底部工具及顏色排，上方導覽 |
| 平板 ≥768px | 4 欄 | 4 欄 | 直向沿用底部工具 |
| 寬 ≥900px 且高 ≥560px | 4 欄 | 4 欄，≥1200px 為 5 欄 | 左側繪圖、右側儲存／全螢幕／更多，底部顏色 |
| 橫向且高 ≤500px | 4 欄 | 4 欄 | 縮減上下間距，保留顏色排與完整圖片 |

主按鈕觸控範圍至少 44×44px，一般導覽 48×48px。極窄 ≤360px 的色票每格 38×44px，以容納八個顏色入口。粗細滑桿觸控高度 44px。畫布使用 Pointer Events、pointer capture 與 touch-action:none；不觸發頁面捲動或選字。

## 視覺 token 與狀態

| Token | 值 |
|---|---|
| 背景／畫布 | #F7FAFC／#FFFFFF |
| 文字／次要文字 | #263238／#607D8B |
| 邊線／重點 | #E8EEF2／#087BAC |
| 選取工具底色／輪廓 | #FFF0BD／#E9BD44 |
| 分類卡 | 淡粉、淡黃、淡綠、淡紫、淡藍、淡橘、淡草綠 |
| 字體 | 系統繁中字體；不另載外部字體 |
| 圓角 | 卡片與對話框 24px，工具 14–16px |

選取工具有底色與輪廓；色票選取有外圈；不可復原或還原時按鈕停用。非同步切圖／復原期間阻擋重入，成功或失敗後恢復操作。儲存與下載錯誤以短暫 status 提示呈現，平常畫布不顯示技術文字。

錯誤或儲存提示保留輔助科技 status；圖示有文字替代，鍵盤焦點有外框；尊重 reduced-motion。對話框可以點外面、關閉或 Escape 收起。舊分頁阻擋資料升級時，最長等待三秒後仍可操作，提示關閉其他畫室分頁並重新整理以恢復保存；不清除既有資料。另一個分頁升級資料時，本頁釋放連線並提示「畫室已在其他分頁更新，回到首頁會重新整理」，之後不再誤報儲存空間不足；回到首頁時自動重新整理。
