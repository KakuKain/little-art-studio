# V46 結構改善驗收

2026-10-07。依賴由 package-lock.json 固定；本輪 `npm run build` 與 `npm test` 均成功結束（exit 0）。瀏覽器操作透過 Codex 原生瀏覽器工具進行；未執行舊版依賴私有全域變數的 Playwright 腳本。

- 全 57 張素材：XML、viewBox、背景、區域 ID、群組契約。
- 全 57 張素材：拆分前後白底及著色外觀比對；穩定 ID。
- 全 57 張素材：背景隔離及語意區域取樣。
- 安娜、艾莎、莫娜：簡化服裝跨舊補丁邊界連續填色。
- 夜煞滑翔圖：六個爪子獨立區域。
- 四張簡化公主：填色保持在輪廓內，貝兒使用已放大的玫瑰作為參考。
- 操作歷史：同作品復原、分支取代還原、20 步窗口、檢查點整理。
- IndexedDB：v1 草稿遷移、保留舊相簿、重開作品及游標、相簿不重複。
- IndexedDB：舊分頁阻擋升級時可恢復；排隊開啟逾時不阻擋首頁，遲到的連線會關閉，舊作品不刪除。
- Service Worker：精簡模組介面、離線首頁、素材快取保留、只清理本專案舊介面。
- 原生 Canvas：240 段筆畫的局部繪製、區域限制、局部橡皮擦；最後一輪空白約 242 ms、區域約 870 ms，均通過 1000 ms 回歸上限。時間受執行環境影響；裁切遮罩與完整遮罩的偏移、邊界、橡皮擦結果相同。此數字不是手機真機效能數據。
