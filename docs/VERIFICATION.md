# V49 彩虹筆漸層、進入網站與上一頁

本機驗收：彩虹筆 2026-10-08，進入網站與上一頁 2026-10-10。

## 彩虹筆漸層

問題：彩虹筆每一段（兩個取樣點之間）只用一個顏色，快速畫出的長線變成數個純色色塊。V47 起即如此，不是 V48 重構造成。修正：每段以線性漸層從上一段結尾色畫到本段結尾色，色標間隔不超過 15°，避免 RGB 內插變灰；起訖點相同時改用純色。

- `npm test` 成功：31 項單元測試，新增的像素測試在只有兩個取樣點的長線上量測 6 個位置的色相與飽和度，修正前失敗、修正後通過。重播沿用同一支筆，縮放後顏色相同。
- 瀏覽器：空白畫布以 30px 彩虹筆快速畫兩條長線（各 3 個取樣點），修正前為兩段純色，修正後為連續漸層。

## 進入網站與上一頁

- 問題 1：離開時若停在畫布，網址保留 `#draw`，重新進入會直接開啟畫布。修正：每次載入清除 `#draw` 並停在首頁；從瀏覽器頁面快取還原時也回到首頁。
- 問題 2：上一頁時若指標仍按在畫布上（滑鼠側鍵「上一頁」會在畫布觸發按下、或返回手勢從畫布開始），畫布被隱藏後收不到放開事件，筆畫一直處於進行中，之後所有點擊都被擋下。V47 起即如此。修正：只有主要按鍵（觸控、觸控筆、滑鼠左鍵）下筆；離開畫布或失去指標捕捉時結束並保存該筆畫。
- `npm test` 成功（31 項單元測試及全部回歸）。這些修正在 `app.js` 的 DOM 事件中，沒有自動測試，以下為瀏覽器驗證。
- 瀏覽器（新的來源，無舊快取）：重現卡住狀態（畫布上按下側鍵後上一頁，點圖片無反應）；修正後同樣操作可開啟獅子；按住主要按鍵時上一頁，回到首頁可開啟大象，該筆畫已保存。在畫布頁重新整理後停在首頁分類總覽、網址不含 `#draw`，選獅子可接續原作品與復原。從其他頁面上一頁返回時此瀏覽器重新載入頁面，同樣停在首頁；頁面快取還原（`pageshow` persisted）的路徑未能在此瀏覽器觸發，只經程式檢查。
